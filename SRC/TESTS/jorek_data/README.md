# JOREK test data

`circular_equilibrium_restart.h5` (400 KB) is a JOREK model-303, circular,
fixed-boundary restart used as a reader smoke fixture: 490 nodes, 476
elements, seven variables, four degrees per node, one toroidal harmonic,
cubic Bezier geometry, `F0 = 10`. SHA-256:
`8aa18910304f3b3bbbbb7641ea10d0c856952ca124fd121c0182ba35c52404d5`.

Provenance: generated by JOREK from the input archived as
`runs/wp3_jorek/circular_equilibrium_input` in the flux_pumping repository
(`gitlab.tugraz.at:plasma/proj/rmp/flux_pumping`), where the same restart is
kept next to its input and run records. It exercises the restart format and
the field-backend plumbing only; it is not a physics case.

`SRC/TESTS/test_jorek_restart_smoke.f90` consumes it through the
`test_jorek_restart_smoke` ctest target registered at the end of the
top-level `CMakeLists.txt` whenever the JOREK backend
(`-DGORILLA_ENABLE_JOREK=ON`) is present and enabled.
